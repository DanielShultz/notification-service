# Notification service

Общий профиль: `D:\Server\AGENTS.md`. Для PHP/backend используй `$backend-service-design`.
Пользователь постоянно разрешил pre-task backup commit/push своих правок и
финальный commit/tag/push после обязательных проверок. Явный запрет в текущей
задаче имеет приоритет. Не включать незавершённую работу другого чата и секреты.
Применяй `$server-project-versioning`, затем `$server-git-autosave`.
Версия этого репозитория — `VERSION`; миграции и runtime проверяются отдельно.
Push не разрешает деплой, restart, миграции или изменение данных.
Полная политика: `D:\Server\documentation\server\git-autosave.md`.
